Features

Everything you need to ship agents with confidence

From the first scenario to the release gate, Waypoint keeps training, evaluation, and review in one workflow.

  • Scenario library

    Build reusable tasks with real tools, files, and edge cases, then organize them into suites your whole team can run.

  • Replayable runs

    Step through every tool call, message, and decision. See what the agent saw at the exact moment things went wrong.

  • Graded evaluations

    Combine programmatic checks with rubric-based grading so every run gets a score you can explain and defend.

  • Regression tracking

    Compare prompts, models, and tool versions side by side, and catch quality drops before they reach a release.

  • Isolated sandboxes

    Every run gets its own filesystem and network policy, so agents can take real actions without touching real systems.

  • Team review

    Annotate transcripts, flag failures, and turn a reviewer's notes into new scenarios with a single click.

How it works

From first scenario to release gate in three steps

  1. 01

    Define scenarios

    Describe the task, the tools available, and what a good outcome looks like. Start from a template or import real transcripts.

  2. 02

    Run your agent

    Point Waypoint at your agent and run the suite in parallel sandboxes, on demand or on every pull request.

  3. 03

    Review and improve

    Read the scores, replay the failures, and feed what you learn back into prompts, tools, and new scenarios.

FAQ

Questions, answered

Can't find what you're looking for? Send us a note.

Which agent frameworks does Waypoint support?

Waypoint talks to your agent through a small HTTP or command-line adapter, so it works with any framework or a custom loop. If your agent can be started from a script, it can be evaluated.

Where do runs execute?

Each run executes in an isolated sandbox with its own filesystem and network policy. Use hosted runners, or bring your own infrastructure.

Can we plug it into our CI pipeline?

Yes. Trigger a suite from your pipeline and fail the build when a score drops below the threshold you set.
